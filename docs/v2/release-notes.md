# AgentCheck-Biz V2 RC1

基于 AgentCheck 的业务结果验证候选版。新增独立源码复现、当前运行的恢复页面、平台启动/健康检查/停止，以及可重跑的 A/B/C 故障演示与重复缺陷门禁。

从源码包解压后按 `docs/v2/delivery.md` 操作；源码文件由 `SOURCE-SHA256.json` 逐项绑定。安装锁定依赖后执行 `scripts/delivery.py demo`，再用 `serve` 打开页面。具体命令、资源与停止方式均在交付说明中。

本轮无新增付费模型请求。验收结果见发布附件 `d35-results.json`，当前提交的 GitHub Actions 链接附在本页。D33 远程红绿灯和 D34 真实模型结果属于历史实验，不能当成本候选版重新执行的模型样本。

**候选版保留项：独立第三方试用反馈尚未取得。** 已提供 `docs/v2/trial.md`，待实际参与者操作后记录原话、卡点和复验。自动化与项目所有者试用不替代独立试用。本版本不声明生产可靠性或端到端 exactly-once；Gitea 无足够观察证据时保守停止。

许可证和来源贡献说明见 `LICENSE` 与 `UPSTREAM.md`。源码包不包含 `.env`、模型凭据、历史数据库或私有运行日志。
